# qagen 사전등록

- 작성 시점: 검증 문단 평가 착수 전
- 작성일: 2026-09-21
- 적용 범위: config.RUN_NAME 으로 지정된 qagen 실행 1회
- 확정 후 본 문서의 가설, 기준, 순서 수정 금지

## 연구 질문

- RQ1: 모델이 스스로 만든 질문(QA_gen)이 골드 질문 정확도의 대리 지표로 쓸 만한지 여부, 외부 반복에 따른 생성 품질 붕괴 여부
- RQ2: QA_gen 보상으로 돌린 외부 루프(qagen)가 RL 전 기본 모델의 self-edit(base_se, SEAL 논문의 Passage + Synthetic 기준선) 대비 검증 정확도를 올리는지 여부

## 가설과 검정 순서

- 1차 가설 H1: qagen_nN > base_se
- H1 통과 기준: 문단 쌍체 부트스트랩(10000회, 시드 0) 95% CI 하한 > 0, 그리고 시드 3개(seed0, seed1, seed2) 각각의 평균 차이 부호가 모두 양수
- 검정 순서 고정: H1 -> H2 -> H3 -> H3b -> H4, 직전 가설 통과 시에만 다음 가설 검정
- H2: qagen_n0 > base_se, 95% CI 하한 > 0
- H3: qagen_nN > qagen_n0, 95% CI 하한 > 0
- H3b: qagen_nN > qagen_randR, 95% CI 하한 > 0
- H4: qagen_nN >= qa0_sup - 3pp 비열등성, 95% CI 하한 > -3pp
- 첫 실패 지점에서 중단, 이후 가설은 "미검정" 으로 보고
- 문단 대응은 타이틀 기준, 양쪽 조건에 모두 있는 문단만 사용
- 모든 난수 추출은 고정 시드, 판정 수치는 report.py 가 원자료에서 계산

## RQ1 1차 지표

- 문단 내 Spearman 상관(생성 질문으로 잰 self-edit 정확도 vs 골드 질문으로 잰 정확도)의 문단 평균, 통과 기준: 문단 부트스트랩 95% CI 하한 > 0
- 귀무 기준선: 다른 문단의 질문으로 잰 정확도와 골드 정확도 사이의 같은 상관

## 2차 지표

- contains-match 정확도, SQuAD F1 정확도
- 타이틀 클러스터 부트스트랩(검증 문단 200개가 약 47개 위키 타이틀에서 유래): 1차 대비의 강건성 열
- 생성 질문 기준 최적 self-edit 과 골드 질문 기준 최적 self-edit 의 Cohen's kappa
- 외부 반복별 파싱률, 후보당 질문쌍 수, 문단 내 답 포함률, 중복률, 골드 커버리지, 생성 질문의 closed-book 정확도

## 검출력

- 최소 검출 가능 효과: 약 3.5pp (추정)
- 근거: 검증 문단 200개, SEAL 보고 수준의 문단 간 분산 가정 - 사전 측정값이 아니므로 확정 수치로 인용 금지

## 사전 고정 사항

- 검증 문단 200개는 최종 평가 전까지 열람, 조정, 선별 금지 - 개발과 파일럿은 dev 30문단만 사용
- 외부 반복 수 N=3 사전 고정 - 결과를 보고 반복 수를 고르지 않음
- 판정자 모델, 판정 프롬프트, TTT 하이퍼파라미터는 본 문서 확정 시점의 config 값으로 동결
- 조건 목록, 보고 순서, 통계 절차는 report.py 에 고정 - 실행 후 추가한 조건이나 사후 지표로 1차 판정 대체 금지

## 보고 원칙

- 부정 결과 그대로 보고, 가설 실패 시 사후 가설로 바꿔 서술하지 않음
- 미측정 항목은 "미측정" 으로 표기, 추정치는 추정으로 표기
- 절대 정확도는 SEAL 공개 수치와 직접 비교 불가 - 모델, 판정자, TTT 패딩이 다름
